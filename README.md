📌 Project Overview

This project demonstrates the design, configuration, and implementation of a three-router enterprise network using Cisco 2811, 4331 routers in Cisco Packet Tracer.

<b>The network consists of three routers</b>:

<b>Gateway Router</b>: Provides connectivity for VoIP and Data networks.
<b>ISP Router</b>: Acts as the intermediate WAN router and provides a loopback interface for connectivity testing.
<b>IT Solution Router</b>: Provides connectivity for Wired LAN and Wireless LAN networks.

The project focuses on practical networking concepts relevant to CCNP Enterprise studies and real-world network engineering.

🎯 Project Objectives
Design a three-router enterprise network.
Implement IPv4 addressing and subnetting.
Configure VLAN-based network segmentation.
Implement Router-on-a-Stick architecture.
Configure IEEE 802.1Q trunking.
Establish point-to-point serial WAN connectivity.
Configure static and default routing.
Implement route summarization.
Verify end-to-end network connectivity.
Practice network troubleshooting using Cisco IOS commands.

# Three_Router_Static_Lab
Enterprise network lab using Cisco 2811 routers and Packet Tracer. Demonstrates VLAN segmentation, Router-on-a-Stick, IPv4 subnetting, serial WAN connectivity, static routing, route summarization, and end-to-end network troubleshooting.
